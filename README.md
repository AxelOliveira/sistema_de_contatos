# 📱 Sistema de Contatos (CLI)

Projeto desenvolvido em Python para gerenciamento de contatos via terminal.

## 🚀 Funcionalidades

- Adicionar contatos
- Listar contatos
- Remover contatos
- Persistência em arquivo (.txt)

## 🛠 Tecnologias

- Python 3

## 📂 Estrutura

- `main.py` → código principal
- `contatos.txt` → armazenamento dos dados

## ▶️ Como executar

```bash
python main.py
